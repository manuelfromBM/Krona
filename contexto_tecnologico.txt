2. BACKEND (apps/backend) - @krona/backend
====================================================================
Framework: NestJS 11 (@nestjs/common, core, platform-express, config, jwt)
Lenguaje: TypeScript 5.7
Base de datos: PostgreSQL, accedida via Prisma ORM (prisma / @prisma/client v7.6)
  - Adaptador: @prisma/adapter-neon (Neon serverless Postgres)
  - Variables de entorno: DATABASE_URL, DIRECT_URL, JWT_SECRET (.env)
  - Schema actual (apps/backend/prisma/schema.prisma) define SOLO:
      User (CLIENT/PROVIDER), ProviderProfile, Service, Appointment
    No existen modelos para Post/Comment/Like/SavedPost (feed) ni nada de
    "profile" mas alla de ProviderProfile -> el modulo feed y el modulo
    profile no tienen respaldo de base de datos todavia.
Autenticacion: JWT (@nestjs/jwt) + bcryptjs para hashing de contraseñas.
Validacion: class-validator + class-transformer (DTOs).
Arquitectura interna: estilo Clean/Hexagonal por modulo, con carpetas:
  application/ (usecases), domain/ (entities, repositories),
  infrastructure/ (implementaciones de repos con Prisma),
  presentation/ (controllers), dto/

        real de registro (hash bcrypt, chequeo de email duplicado, firma JWT).

5. DOMINIO DE NEGOCIO (inferido del codigo)
====================================================================
Krona parece ser una plataforma que conecta:
  - Clientes (CLIENT) que agendan citas/servicios y ven un feed social.
  - Proveedores/negocios (PROVIDER / "pyme") que gestionan su perfil,
    servicios, agenda, dashboard con estadisticas (free/premium) y staff.
Funcionalidades clave (segun frontend ya construido en web/mobile, por
  delante del backend): autenticacion con roles, reserva de citas
  (appointments/services/booking), feed social (posts, comentarios, likes,
  guardados, sugerencias), perfiles, metodos de pago, mapa de ubicacion,
  notificaciones.
El backend hoy solo soporta: registro de usuario (CLIENT) con JWT. Todo
  lo demas (booking, feed, profile, login/logout/refresh) esta modelado
  en el frontend pero sin API funcional detras todavia.
